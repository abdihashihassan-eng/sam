# SAHAN DATA – Platform

![SAHAN DATA Logo](https://via.placeholder.com/150x50?text=SAHAN+DATA)

**SAHAN DATA** waa repository-ga rasmiga ah ee mashruuca **SAHAN DATA**, oo ah madal dhijitaal ah oo lagu iibsado xidhmada isgaarsiinta Soomaaliya (data, ku hadal, iyo isku darkood). Waxay isku xidhaa shirkadaha isgaarsiinta, macaamiisha, iyo nidaamka abaalmarinta.

---

## 📖 Sharaxaad

SAHAN DATA waa nidaam buuxa oo leh:

- **Iibsi 5-tallaabo ah** (Shirkad → Adeeg → Qorshe → Bixin → Xaqiiji) oo leh USSD auto-dial.
- **Nidaam soo-jiidasho (Referral)** – macaamiisha waxay noqdaan iibiyeyaal waxayna helaan bonus points.
- **6 tartan** (todobaadle, bille, sanadeed) oo abaalmarin lacageed iyo xidhmo bilaash ah.
- **Live Leaderboard** oo muujiya hogaamiyayaasha tartamada.
- **Admin Panel** oo si buuxda u maamula dalabyada, shirkadaha, adeegyada, qorshayaasha, iyo macaamiisha.
- **Dashboard-ka macaamiisha** oo muujiya taariikhda iibka, soo-jiidashada, iyo dhibcaha.
